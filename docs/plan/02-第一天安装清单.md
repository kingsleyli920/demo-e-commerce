## 2. 项目初始化（M1）

```bash
pnpm create next-app@latest . --ts --tailwind --eslint --app --src-dir --turbopack   # 在 demo-e-commerce 目录内
pnpm dlx shadcn@latest init
pnpm dlx shadcn@latest mcp init --client claude

# 数据层 + 鉴权
pnpm add drizzle-orm pg zod better-auth && pnpm add -D drizzle-kit @types/pg tsx
cat > docker-compose.yml <<'YML'
services:
  postgres:
    image: postgres:16
    ports: ["5432:5432"]
    environment: { POSTGRES_USER: shop, POSTGRES_PASSWORD: shop, POSTGRES_DB: shop }
    volumes: ["pgdata:/var/lib/postgresql/data"]
volumes: { pgdata: {} }
YML
docker compose up -d postgres
docker compose exec postgres psql -U shop -c 'CREATE DATABASE shop_test;'

# 测试
pnpm add -D vitest @testing-library/react @testing-library/jest-dom @testing-library/user-event jsdom @playwright/test
pnpm exec playwright install chromium

# 工程化
pnpm add -D prettier
```

`.env.local`：`DATABASE_URL=postgres://shop:shop@localhost:5432/shop`、`DATABASE_URL_TEST=postgres://shop:shop@localhost:5432/shop_test`、`BETTER_AUTH_SECRET=<随机>`、`BETTER_AUTH_URL=http://localhost:3000`、`ORDER_EXPIRE_MINUTES=15`、`CRON_SECRET=<随机>`。

`package.json` scripts 约定：`dev` · `build` · `lint` · `typecheck` · `db:generate` · `db:migrate` · `db:seed` · `db:reset`（drop+migrate+seed） · `test:unit` · `test:e2e` · `test`。
