# ADR-0002 技术栈：Next.js 16 单仓 + Drizzle/Postgres + Better Auth

- 状态：已接受（2026-08-22；2026-08-23 M1 按实际安装版本校准）
- 来源：`IMPLEMENTATION_BRIEF.md` §3–§4、`docs/plan/02`

## 决策

| 层   | 选型（M1 实际版本）                                                                                              |
| ---- | ---------------------------------------------------------------------------------------------------------------- |
| 框架 | Next.js 16.3（App Router、Server Actions、Route Handlers、`proxy.ts`）+ TypeScript 5.9，单仓 `src/`              |
| UI   | Tailwind CSS v4.3 + shadcn/ui（radix-nova 预设，`radix-ui` 单包）+ lucide-react + sonner                         |
| 数据 | Drizzle ORM 0.45 + drizzle-kit 0.31 + PostgreSQL 16（Docker Compose，宿主机 5433）；金额整数「分」               |
| 鉴权 | Better Auth 1.7（邮箱密码 + Drizzle adapter + `role` additionalField）；`nextCookies` 插件                       |
| 测试 | Vitest 4（projects：node 直连 `shop_test` / jsdom 组件）+ @vitest/coverage-v8 阈值 + Playwright 1.62（chromium） |
| CI   | GitHub Actions（services postgres:16 → lint → typecheck → migrate → unit → build → e2e）                         |
| P1   | Vercel AI SDK + `@ai-sdk/anthropic`（`claude-sonnet-5`），M5 前不安装                                            |

## 分层红线

1. `src/server/services/**` 只依赖 `db` + `dto` + drizzle/zod，不 import `next/*`、React、AI SDK。
2. 所有写操作走 service（事务内）；页面与 Server Actions 只做 zod 校验与调用。
3. 金额全程整数分，展示层 `formatPrice`。
4. 不手改 `drizzle/` migrations。

## M1 校准的小决策

- Postgres 宿主机端口用 5433（本机 5432 被 Homebrew postgresql@17 常驻占用）；`POSTGRES_PORT` 可覆盖。
- 根布局 `export const dynamic = 'force-dynamic'`：全站动态 SSR，避免构建期预渲染连库。
- 关闭 `typedRoutes`（路由逐里程碑创建，避免类型阻塞）；去掉 `next/font/google`，使用系统字体栈保证离线构建。
- `forbidden()` 需 `experimental.authInterrupts`，用于 `/admin` 403 页。
