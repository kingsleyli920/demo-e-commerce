# ADR-0001 范围收敛：P0 闭环优先，P1 需门槛

- 状态：已接受（2026-08-22 用户拍板；2026-08-23 M1 落地）
- 来源：`IMPLEMENTATION_BRIEF.md` §1–§2、`docs/plan/01` §1

## 背景

项目目标是在 24–30 小时内交付一个可 10 分钟完整演示的单商户电商 Demo，并以仓库本身展示人机协作过程。早期扩展版规划（4–5 周）超出时间盒。

## 决策

1. **P0（M1–M4，≈24h）缺一不可**：账号、目录/搜索、详情/SKU、库存（并发不超卖）、购物车、Mock 结算/支付/超时、订单、最小后台、完整测试 + CI、AI 协作留痕。
2. **P1 AI 导购（M5，≈6h）不自动开始**：须同时满足「P0 全部验收通过」「独立 Review 无 Critical/High」「累计 ≤ 24h 且剩余 ≥ 6h」。
3. **明确不做**：真实支付、多商户、对外 MCP、营销玩法、物流对接、推荐、图搜、i18n、移动端、游客购物车、monorepo、向量检索、OpenSpec、全程录屏、公网部署。
4. 运行环境：本地 Docker Compose + PostgreSQL 16；UI 与文案中文；协作过程以仓库留痕 + 3–5 分钟录屏展示。

## 后果

- 超预算 30% 时只能删减 UI 精修 / 额外抽象 / 非核心细节，不得删减任何验收项、测试与业务规则。
- 范围回弹（评价、优惠券、AI）一律进 P1 列表。
